# Design Note Template

Use this template for Latticra-style systems design notes.

```md
# Design Note: Feature Name

## Purpose

What problem does this feature solve?

## User model

Who uses it, and what do they need from it?

## System model

What parts of the system are involved?

## Data model

What information does the feature store, read, write, or transform?

## Security model

What can go wrong? What assumptions does the feature make? How is risk reduced?

## Examples

Show normal usage and failure cases.

## Evidence

What tests, demos, logs, or proofs support the claims?

## Current status

Built, prototype, design-only, or future work?

## Next steps

What should happen next?
```
