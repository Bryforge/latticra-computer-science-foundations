# Module 0 — Orientation

## Purpose

This module introduces the course, the learner mindset, and the systems-centered direction of Latticra — Foundations of Computer Science.

## Core questions

- What is computer science?
- How is computer science different from programming?
- Why do systems matter?
- What does it mean to learn from first principles?

## Key ideas

Computer science studies computation, information, algorithms, structure, and the machines and systems that make computation real.

Programming is one expression of computer science, but computer science is broader. It includes logic, representation, memory, architecture, operating systems, programming languages, and security.

## Course arc

```text
logic → code → memory → machines → operating systems → languages → security → Latticra
```
