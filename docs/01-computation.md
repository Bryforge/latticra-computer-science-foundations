# Module 1 — Computation

## Purpose

This module introduces the foundations of computation: representation, logic, and algorithms.

## Core questions

- How do computers represent information?
- Why is binary enough to build complex systems?
- What is an algorithm?
- How does abstraction make computation manageable?

## Key ideas

Computers operate on representations. Numbers, text, images, instructions, and files all become structured patterns of bits.

Logic gives us a way to reason about truth, decision-making, and program behavior. Algorithms give us repeatable procedures for solving problems.

## Topics

- Bits and bytes
- Binary numbers
- Boolean logic
- Truth tables
- Algorithms
- Abstraction

## Exercise

Create truth tables for `AND`, `OR`, and `NOT`. Then explain how these simple operations can support larger decisions in a program.
