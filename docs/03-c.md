# Module 3 — C and Systems Programming

## Purpose

This module introduces C as a foundation for understanding memory, compilation, and systems-level programming.

## Core questions

- Why is C important in computer science?
- What does a compiler do?
- What is memory?
- What are pointers and why do they matter?
- How can C be used responsibly?

## Key ideas

C gives learners a close view of how software relates to memory and machines. That power requires discipline. Systems programming should be careful, defensive, and honest about risk.

## Topics

- Source files and compilation
- `main`
- Types
- Arrays
- Strings
- Pointers
- Structs
- Stack and heap
- Manual memory management
- Undefined behavior

## Exercise

Write a small C program that stores a list of integers, prints them, and computes their sum.

## Security note

Memory errors are a major source of real-world vulnerabilities. Learning C should include learning how to avoid unsafe patterns.
