# Module 7 — Programming Languages

## Purpose

This module introduces programming languages as designed systems with syntax, semantics, tooling, and runtime behavior.

## Core questions

- What is a programming language?
- What is syntax?
- What is semantics?
- How do interpreters and compilers work?
- Why do language design choices matter?

## Key ideas

A programming language is more than a notation. It is a structured way to express computation, guide human thought, and shape what systems are easy or difficult to build.

## Topics

- Tokens
- Syntax
- Semantics
- Lexing
- Parsing
- Interpreters
- Compilers
- Type systems
- Runtime environments
- Standard libraries

## Exercise

Design a tiny expression language that supports numbers, addition, subtraction, multiplication, and parentheses. Write examples of valid programs in the language.

## Latticra connection

The Latticra Programming Language should be studied as a language design project: syntax, semantics, runtime behavior, tooling, documentation, and user experience all matter.
