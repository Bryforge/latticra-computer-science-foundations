# Course Map

**Latticra — Foundations of Computer Science** is a structured path from first principles to real systems thinking.

Use this map alongside:

- [`START_HERE.md`](START_HERE.md) for the recommended path
- [`COURSEBOOK.md`](COURSEBOOK.md) for the full lesson text
- [`SYLLABUS.md`](SYLLABUS.md) for pacing and expectations
- [`ASSESSMENT.md`](ASSESSMENT.md) for completion standards
- [`CAPSTONE.md`](CAPSTONE.md) for the final project

## Course sequence

| Module | Topic | Main deliverable |
| --- | --- | --- |
| 0 | Orientation | Learning contract and environment setup |
| 1 | Computation | Binary, logic, and algorithm exercises |
| 2 | Programming | Pseudocode and debugging practice |
| 3 | C and Systems Programming | C program and memory notes |
| 4 | Data Structures | Data structure comparison and stack model |
| 5 | Computer Architecture | Machine execution explanation |
| 6 | Operating Systems | OS layer model and terminal/file lab |
| 7 | Programming Languages | Tiny expression language sketch |
| 8 | Security | Threat model |
| 9 | Latticra Design | Design note and capstone proposal |

## Module 0 — Orientation

Learners set up their environment, learn the course method, and understand why computer science is more than programming.

Core ideas:

- What computer science studies
- Systems thinking
- The relationship between theory and implementation
- How to work through labs and assignments

## Module 1 — Computation

This module introduces the foundations of information, logic, and algorithmic thinking.

Core ideas:

- Binary and representation
- Boolean logic
- Truth tables
- Algorithms
- Abstraction

## Module 2 — Programming

This module introduces the structure of programs and the discipline of precise problem solving.

Core ideas:

- Variables and types
- Control flow
- Functions
- Input and output
- Debugging
- Program structure

## Module 3 — C and Systems Programming

This module introduces C as a foundation for understanding memory, machine-level behavior, and systems software.

Core ideas:

- Compilation
- Pointers
- Arrays and strings
- Structs
- Manual memory management
- Undefined behavior and defensive programming

## Module 4 — Data Structures

This module teaches the structures used to organize data and build larger software systems.

Core ideas:

- Arrays
- Linked lists
- Stacks and queues
- Trees
- Hash maps
- Complexity tradeoffs

## Module 5 — Computer Architecture

This module explains how programs become machine behavior.

Core ideas:

- CPUs and instruction execution
- Memory hierarchy
- Registers
- Assembly concepts
- Buses and devices
- The program/machine boundary

## Module 6 — Operating Systems

This module introduces the operating system as the layer that organizes hardware, programs, memory, files, and users.

Core ideas:

- Processes
- Filesystems
- Terminals and shells
- Virtual memory
- Scheduling
- System calls
- Kernel/user boundaries

## Module 7 — Programming Languages

This module introduces the design and implementation of programming languages.

Core ideas:

- Syntax and semantics
- Lexing and parsing
- Interpreters
- Type systems
- Runtime environments
- Compiler basics

## Module 8 — Security

This module introduces security as a core design discipline rather than an afterthought.

Core ideas:

- Threat modeling
- Memory safety
- Input validation
- Least privilege
- Isolation
- Defensive engineering
- Secure systems culture

## Module 9 — Latticra Design

This module connects the course foundations to the design of the Latticra Operating System and the Latticra Programming Language.

Core ideas:

- System identity
- Language and OS co-design
- Trustworthy computing
- Human-centered command environments
- Evidence-bound claims
- Capstone design proposal

## Capstone

The final course project asks learners to design and document a small computing system component. Examples include:

- A command shell model
- A small interpreter
- A virtual filesystem sketch
- A memory-safe data structure library
- A threat model for a simple system
- A Latticra-inspired systems design proposal

See [`CAPSTONE.md`](CAPSTONE.md) for the full guide.
