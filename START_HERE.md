# Start Here

Welcome to **Latticra — Foundations of Computer Science**.

This is the recommended path through the course.

## What this course teaches

This course teaches computer science from a systems-minded perspective. It begins with computation and programming, then builds toward C, data structures, architecture, operating systems, programming languages, security, and Latticra design.

The course arc is:

```text
logic → code → memory → machines → operating systems → languages → security → Latticra
```

## Recommended order

1. Read `README.md`.
2. Read `SYLLABUS.md`.
3. Read `COURSE.md`.
4. Work through `COURSEBOOK.md` from Module 0 to Module 9.
5. Complete the assignments in `assignments/`.
6. Complete the labs in `labs/`.
7. Use `GLOSSARY.md` whenever a term is unfamiliar.
8. Complete `CAPSTONE.md`.
9. Use `ASSESSMENT.md` to check whether the course is complete.

## Completion standard

The course is complete when you have:

- Read all modules in `COURSEBOOK.md`
- Completed all assignments
- Completed all labs
- Written notes for every module
- Completed the capstone project
- Explained the course arc in your own words

## Learning posture

Do not rush past confusion. In systems work, confusion often points to the exact place where learning needs to happen.

When you get stuck:

1. Restate the problem in plain English.
2. Write down what you know.
3. Identify the first unknown.
4. Build the smallest possible test.
5. Record what happened.

That habit is part of computer science.
