# Glossary

A working glossary for **Latticra — Foundations of Computer Science**.

## Algorithm

A finite, step-by-step method for solving a problem.

## Abstraction

A simplified model that hides unnecessary detail while preserving what matters.

## Architecture

The structure of a computing machine or system, including how its parts relate and communicate.

## Array

A data structure that stores items in contiguous positions, usually allowing direct access by index.

## Attack surface

The set of places where a system can be interacted with or attacked.

## Binary

A base-2 number system using only `0` and `1`.

## Bit

The smallest common unit of digital information, usually represented as `0` or `1`.

## Boolean logic

Logic based on true and false values, commonly using operations such as AND, OR, and NOT.

## Byte

A group of 8 bits.

## Compiler

A program that translates source code into another form, often machine code, bytecode, or an intermediate representation.

## Control flow

The order in which program instructions execute.

## Data structure

A way of organizing data so a program can use it effectively.

## Debugging

The process of investigating, understanding, and fixing incorrect program behavior.

## File system

The operating system structure that organizes stored data into files, directories, paths, metadata, and permissions.

## Function

A named block of behavior that can receive input, perform work, and optionally return output.

## Heap

A region of memory commonly used for dynamic allocation.

## Interpreter

A program that directly executes or evaluates another program representation.

## Kernel

The privileged core of an operating system that manages resources and hardware access.

## Least privilege

The principle that a program or user should have only the access necessary to perform its task.

## Memory

The working storage used by running programs.

## Operating system

System software that manages hardware, programs, memory, files, permissions, and user interaction.

## Parser

A program component that turns tokens into structured syntax.

## Pointer

A value that refers to a memory address.

## Process

A running program with execution state managed by the operating system.

## Program

A precise description of computation intended for execution by a machine and understanding by humans.

## Register

A small, fast storage location inside a CPU.

## Security

The discipline of designing, building, testing, and documenting systems to protect assets under specific assumptions.

## Shell

A command interpreter that lets a user launch programs and interact with the operating system.

## Stack

A last-in, first-out data structure; also a memory region used for function calls and local state.

## Syntax

The form or grammar of valid language expressions.

## Semantics

The meaning or behavior of language expressions.

## System call

A controlled request from a user program to the operating system kernel.

## Threat model

A structured description of assets, actors, threats, attack surfaces, mitigations, and assumptions.

## Token

A meaningful unit of source text, such as a number, identifier, keyword, or operator.

## Type

A classification of values and operations in a programming language.

## Undefined behavior

Program behavior that a language specification does not define, often dangerous in systems languages such as C.
