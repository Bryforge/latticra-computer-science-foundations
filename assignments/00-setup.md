# Assignment 00 — Setup and Learning Contract

## Goal

Prepare your learning environment and write a short learning contract for the course.

## Tasks

1. Install or confirm access to a terminal.
2. Install or confirm access to Git.
3. Install or confirm access to a text editor.
4. Install or confirm access to a C compiler such as `clang` or `gcc`.
5. Create a course notes folder on your machine.
6. Write a short learning contract.

## Learning contract prompts

Answer the following:

- Why am I taking this course?
- What do I want to understand about computers?
- What systems topic interests me most?
- How many hours per week will I commit?
- What will I do when I get stuck?

## Completion checklist

- [ ] Terminal is available
- [ ] Git is available
- [ ] Text editor is available
- [ ] C compiler is available
- [ ] Course notes folder exists
- [ ] Learning contract is written
