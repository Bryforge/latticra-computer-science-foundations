# Module 4 — Data Structures

## Purpose

This module introduces the structures used to organize data and build larger programs.

## Core questions

- Why do data structures matter?
- How do different structures create different tradeoffs?
- What makes an operation efficient or inefficient?
- How does structure shape program design?

## Key ideas

A data structure is a way of organizing information so that programs can use it effectively. Different structures make some operations easier and others harder.

## Topics

- Arrays
- Linked lists
- Stacks
- Queues
- Trees
- Hash maps
- Big-O intuition
- Choosing the right structure

## Exercise

Compare an array, linked list, stack, and queue. For each one, explain what it is good for and what it is not good for.

## Implementation challenge

Implement a stack using an array. Include `push`, `pop`, and `peek` operations.
