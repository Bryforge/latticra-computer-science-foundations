## Self-assessment questions

A learner should be able to answer these without notes.

1. What is the difference between programming and computer science?
2. Why can binary represent complex information?
3. What is an algorithm?
4. What is control flow?
5. Why does C expose more risk than many higher-level languages?
6. What is a pointer?
7. Why do data structures involve tradeoffs?
8. What does a CPU do?
9. What does an operating system manage?
10. What is a system call?
11. What is the difference between syntax and semantics?
12. What is a threat model?
13. What does least privilege mean?
14. Why should security claims be evidence-bound?
15. How does Latticra connect operating systems and programming languages?

## Completion standard

The course is complete when the learner can explain the full arc:

```text
logic → code → memory → machines → operating systems → languages → security → Latticra
```

and support that explanation with examples from the labs, assignments, and capstone.
