# Module 5 — Computer Architecture

## Purpose

This module explains how programs become machine behavior.

## Core questions

- What does a CPU do?
- How does memory interact with execution?
- What are instructions?
- How does architecture shape software?

## Key ideas

Computer architecture is the bridge between abstract programs and physical machines. Understanding architecture helps learners understand performance, memory, security, and operating systems.

## Topics

- CPU basics
- Registers
- Instructions
- Memory hierarchy
- Stack and heap concepts
- Assembly intuition
- Devices and buses
- Program execution

## Exercise

Trace a simple expression such as `x = a + b` from source code to a conceptual machine-level operation.

## Reflection

Explain why systems programmers need to understand architecture even when they mostly write high-level code.
