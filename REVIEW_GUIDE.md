# Review Guide

Use this guide after completing **Latticra — Foundations of Computer Science**.

## The core arc

Be able to explain this sequence:

```text
logic → code → memory → machines → operating systems → languages → security → Latticra
```

## Module review

### Module 0 — Orientation

Explain:

- What computer science studies
- Why programming is only part of computer science
- Why systems thinking matters

### Module 1 — Computation

Explain:

- Bits and bytes
- Binary representation
- Boolean logic
- Algorithms
- Abstraction

### Module 2 — Programming

Explain:

- Variables
- Types
- Control flow
- Functions
- Debugging
- Pseudocode

### Module 3 — C and Systems Programming

Explain:

- Compilation
- Pointers
- Arrays
- Stack and heap
- Manual memory responsibility
- Why C requires discipline

### Module 4 — Data Structures

Explain:

- Arrays
- Lists
- Stacks
- Queues
- Trees
- Maps
- Tradeoffs

### Module 5 — Computer Architecture

Explain:

- CPU
- Registers
- Memory hierarchy
- Instructions
- Fetch-decode-execute
- Why software is shaped by hardware

### Module 6 — Operating Systems

Explain:

- Kernel
- Processes
- Filesystems
- Shells
- System calls
- Permissions

### Module 7 — Programming Languages

Explain:

- Syntax
- Semantics
- Tokens
- Parsing
- Interpreters
- Compilers
- Type systems

### Module 8 — Security

Explain:

- Threat models
- Attack surface
- Least privilege
- Memory safety
- Evidence-bound claims

### Module 9 — Latticra Design

Explain:

- OS/language co-design
- Documentation as engineering
- Honest project status
- Systems design notes
- Capstone planning

## Final oral exam prompt

Answer this in your own words:

> How does a human idea become a secure computing system?

A strong answer should mention representation, programs, memory, machines, operating systems, languages, security assumptions, testing, and documentation.

## Final written prompt

Write a two-page reflection:

> What did this course teach me about building Latticra or understanding computer systems?

Include at least one example from each of these areas:

- Computation
- Programming
- C or memory
- Operating systems
- Programming languages
- Security
