# Assignment 02 — Build a Small Interpreter

## Goal

Design and sketch a tiny interpreter for arithmetic expressions.

## Language requirements

Your expression language should support:

- Whole numbers
- Addition
- Subtraction
- Multiplication
- Division
- Parentheses

Example programs:

```text
1 + 2
4 * 5
(10 + 2) / 3
```

## Tasks

1. Define the language rules in plain English.
2. List the tokens your language needs.
3. Write example valid expressions.
4. Write example invalid expressions.
5. Sketch how an interpreter would evaluate an expression.

## Stretch goal

Implement the interpreter in a programming language of your choice.
