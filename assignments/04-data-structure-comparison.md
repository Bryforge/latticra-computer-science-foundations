# Assignment 04 — Data Structure Comparison

## Goal

Practice choosing data structures based on tradeoffs.

## Scenario

You are designing a small command environment for a systems project. The environment needs to store:

1. Command history
2. Open files
3. Running tasks
4. Named configuration values
5. A directory tree

## Tasks

For each need, choose a data structure and explain why.

Use at least four of these:

- Array
- Linked list
- Stack
- Queue
- Tree
- Hash map

## Required table

Fill out a table like this:

| Need | Chosen structure | Why it fits | Tradeoff |
| --- | --- | --- | --- |
| Command history | Example: array or list | Easy to append and review | May require resizing or traversal |

## Reflection

Answer:

> Why is there no single best data structure for every problem?

## Completion checklist

- [ ] Five system needs addressed
- [ ] At least four data structures used
- [ ] Tradeoffs explained
- [ ] Reflection written
