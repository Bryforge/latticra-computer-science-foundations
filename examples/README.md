# Examples

This directory contains small examples that support **Latticra — Foundations of Computer Science**.

## Current examples

- `c/hello.c` — minimal C program
- `c/sum.c` — array and function example
- `tiny-language/tokens.md` — hand-tokenized expression examples
- `design-note-template.md` — template for Latticra-style systems design notes

Examples should stay small, readable, and connected to the course modules.
