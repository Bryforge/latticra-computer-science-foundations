# Contributing

Thank you for your interest in improving **Latticra — Foundations of Computer Science**.

## Contribution principles

Contributions should be:

- Clear
- Beginner-friendly
- Technically honest
- Systems-minded
- Evidence-bound

## Good contributions

Useful contributions include:

- Fixing typos or unclear explanations
- Improving examples
- Adding exercises
- Adding labs
- Improving module structure
- Adding diagrams in text form
- Clarifying security language

## Course style

When writing course material:

1. Prefer simple explanations before advanced terminology.
2. Show examples.
3. Avoid unsupported claims.
4. Distinguish between fact, design goal, and future work.
5. Keep Latticra references accurate and grounded.

## File organization

- Put lesson material in `docs/`
- Put written or programming assignments in `assignments/`
- Put hands-on labs in `labs/`

## Commit style

Use clear commit messages, such as:

```text
Add module on memory basics
Fix C lab compilation instructions
Expand operating systems glossary
```
