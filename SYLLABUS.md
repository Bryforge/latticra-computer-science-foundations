# Syllabus

## Course title

**Latticra — Foundations of Computer Science**

## Course description

This course introduces computer science from a systems-minded perspective. Learners begin with logic, representation, and algorithms, then move into programming, C, data structures, computer architecture, operating systems, programming language design, security, and the design principles behind Latticra.

The course is intended for learners who want to understand how software, machines, languages, and systems connect.

## Prerequisites

No formal prerequisites are required, but learners should be willing to work carefully through programming exercises, command-line tools, and technical writing.

Helpful background:

- Basic computer use
- Curiosity about programming
- Willingness to use a terminal
- Patience with debugging

## Learning outcomes

By the end of the course, learners should be able to:

- Explain the difference between programming and computer science
- Use binary, logic, and abstraction to reason about computation
- Write small programs using structured programming techniques
- Understand the role of C in systems programming
- Implement basic data structures
- Describe how programs relate to hardware
- Explain core operating system concepts
- Describe how programming languages are designed and implemented
- Apply basic security thinking to software and systems
- Connect computer science foundations to the Latticra project

## Suggested pacing

This course can be completed as a 10-module course.

| Week | Module | Focus |
| --- | --- | --- |
| 1 | Module 0 | Orientation and environment |
| 2 | Module 1 | Computation, binary, and logic |
| 3 | Module 2 | Programming fundamentals |
| 4 | Module 3 | C and systems programming |
| 5 | Module 4 | Data structures |
| 6 | Module 5 | Computer architecture |
| 7 | Module 6 | Operating systems |
| 8 | Module 7 | Programming languages |
| 9 | Module 8 | Security |
| 10 | Module 9 | Latticra design and capstone |

## Assessment model

Suggested grading model:

- Labs: 35%
- Assignments: 35%
- Notes and written reflections: 10%
- Capstone project: 20%

For self-study learners, grading can be replaced with completion checklists and written reflections.

## Tools

Learners may use:

- A terminal
- Git and GitHub
- A C compiler such as `clang` or `gcc`
- A text editor
- Optional: Linux, BSD, macOS, or a virtual machine

## Academic posture

This course values clarity, correctness, humility, and evidence. Learners should distinguish between what has been built, what has been tested, and what is still only proposed.
