# Module 6 — Operating Systems

## Purpose

This module introduces operating systems as the layer that organizes programs, hardware, files, memory, users, and devices.

## Core questions

- What is an operating system?
- What is a process?
- Why do filesystems matter?
- What is the kernel/user boundary?
- How do terminals and shells fit into a system?

## Key ideas

An operating system is not only a user interface. It is a control system for computation. It manages resources, enforces boundaries, and provides abstractions that programs depend on.

## Topics

- Kernels
- Processes
- Threads
- Filesystems
- Terminals and shells
- System calls
- Virtual memory
- Scheduling
- Permissions
- Device abstraction

## Exercise

Draw a simple model showing the relationship between a user, shell, program, system call, kernel, and hardware.

## Latticra connection

Operating system study provides the foundation for thinking clearly about Latticra as a system rather than only as a collection of commands or features.
