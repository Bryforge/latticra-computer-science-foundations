# Module 2 — Programming

## Purpose

This module introduces programming as a disciplined method for expressing computation.

## Core questions

- What is a program?
- How do variables, types, and functions organize computation?
- How do we control the path a program takes?
- What does debugging teach us?

## Key ideas

A program is a precise set of instructions written for both humans and machines. Good programs are not only functional; they are understandable, testable, and structured.

## Topics

- Variables
- Types
- Expressions
- Control flow
- Functions
- Input and output
- Debugging
- Decomposition

## Exercise

Write pseudocode for a simple calculator. Include input, decision-making, and output.

## Reflection

Explain why clear program structure matters more as systems become larger.
